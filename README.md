# 柒柿AI · 静态 Demo

这是 [柒柿AI / Cheese AI](https://github.com/HH-567/cheese-ai) 的静态演示页：内置 310 条精选问答（来自 3.4 万组演示库），在浏览器里完成原问 / 等价问法 / 语义近似的匹配，命中即答，不调用任何后端。

- 在线地址：<https://hh-567.github.io/cheese-ai-demo/>
- 完整版（登录、审核治理、云端兜底、文件/图片、网页搜索）见主仓库。

## 本地运行

```powershell
cd demo-site
python -m http.server 8090
```

打开 <http://127.0.0.1:8090>。

## 说明

- 只演示“本地命中”，未命中时不会调用大模型；
- 数据是共享库的一个子集，完整库 34,657 组 / 139,185 条问法；
- 界面纯静态，无账号、无 Cookie、无查询参数。
